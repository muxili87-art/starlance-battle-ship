# Codex 任务书 04：9 机展示机库、局外轻量养成与未来 IAA/榜单预留接口

> **前置依赖**：完成 [codex-task-03-stages-boss-audio.md](./codex-task-03-stages-boss-audio.md)。
> **核心目标**：打通“出击 → 结算零件 → 局外升级/解锁新战机 → 换流派再开一局”的完整单人循环，并为后续可能接入的激励广告与排行榜留好干净接口。

## 任务清单

1. **高质感像素机库选机界面（`MenuScene.js` 重构）**
   - 默认解锁 `01 赤锋` 与 `02 疾风` 供新人立即体验；其余 7 架可在机库预览高清贴图、定位标签、专属机制说明与「单局试飞」入口。
   - 界面展示清晰的雷达/条形能力对比（`对单火力` / `对群清场` / `生存机动`），玩家一眼看懂选哪架。

2. **局外轻量双轨养成（`localStorage` 持久化）**
   - **6 项通用强化底座**（消耗每局结算产出的「星穹零件」）：
     - 主炮火力、最大耐久、暴击率、晶体磁吸范围、初始能量、零件掉率。
     - **数值曲线原则**：第 1 局即使战败也能在局外升 1–2 级，建立正反馈；满级上限控制在合理倍率内，防止后期数值崩坏破坏弹幕躲避乐趣。
   - **战机解锁进度**：通关对应关卡或累计零件即可解锁新战机。

3. **单局结算与快速重开闭环（`OverlayScene.js`）**
   - 展示本局通关/战败结果、耗时、击杀数、成型构筑流派（含已触发的超武图标）、获得零件数。
   - 提供极简按钮：**「再来一局」**（1 秒直接重开）与 **「返回机库升级」**。

4. **预留 IAA 与挑战模式接口（本阶段只留接口，不接真实广告）**
   - 新建 `src/services/reward-hooks.js` 空实现契约（如 `canOfferRevive()`, `onDoubleRewardRequested()`），默认返回不弹出或直通免费测试开关，确保未来如果要接微信/抖音激励视频或每日固定种子挑战，无需重构核心战斗代码。

## 验收标准
- 刷新页面后，已解锁战机、零件数量、局外强化等级与最高关卡记录均正确保留。
- 战败或通关后点击「再来一局」能在 1 秒内重置状态开局，无残余定时器、声音或贴图泄漏。
- `npm test` 与 `npm run build` 全部通过。
