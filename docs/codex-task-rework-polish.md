# Codex 返工任务书：V2 爽感、视觉质感、9机差异化与音效全量打磨

> **背景**：当前 `v2-solo` 分支只是“能跑通的极简灰盒骨架”，存在 4 个严重影响体验的问题：
> 1. **视觉与特效粗糙**：在精致的像素战机座舱上直接盖了一坨黑底大圆圈靶心；阴影是纯黑椭圆；尾焰是硬三角形；爆炸只是空心圆+7个方块；缺少打击火花、顿帧与震屏。
> 2. **9 机全员换皮**：无论选哪架战机，主炮都是完全一样的“2发蓝杠”，升级三选一只有干瘪的 `+25%火力/+20%射速`，毫无构筑质变。
> 3. **关卡节奏干瘪**：刷怪过少、15 种敌机行为完全一致、40 秒草草出 Boss，Boss 也只是左右画波浪吐圆球。
> 4. **全程静音**：没有开火、命中、爆裂与吃经验的升调音效，缺乏街机反馈。
>
> **目标**：严格按本任务书完成全部 4 大模块返工，把游戏打磨到**“一上手就有高水准街机打击感、9 架战机打法截然不同、越打越爽”**。

---

## 一、明确禁止的反模式（红线，违反即返工）

1. **禁止遮挡战机座舱**：绝对不要在战机正中心画黑底大圆圈靶心！改为仅保留极细的 `3px` 发光判定核（或仅在受击/擦弹/按慢速键时高亮提示圈），把精致的像素战机完整露出来。
2. **禁止纯黑椭圆占位阴影**：阴影必须使用同贴图的暗色半透明副本（`setTintFill(0x02060e).setAlpha(0.36)` 偏移 `(x + 16, y + 22)` 并随横移 `bank` 同步倾转），形成真实的 2.5D 机身轮廓投影。
3. **禁止简陋几何占位特效**：
   - 禁止用 3 个硬三角形画尾焰 → 改用**多节像素焰柱/推进颗粒流**，且对称贴合每架战机的真实双尾喷口位置。
   - 禁止用“空心圆 + 7 个方块”敷衍爆炸 → 击破敌机必须有 **闪白瞬间 + 16~24 颗带重力/阻力的像素火花碎片 + 渐隐像素烟雾团 + 精英/Boss 击破时的微顿帧（`25~35ms`）与相机微震（`shake`）**。
4. **禁止 9 架战机共用同一种主炮子弹**：每架战机必须有自己专属的弹道造型、颜色、机制效果和升级质变。

## 二、4 大必改模块与文件规范

### 模块 1：视觉质感与打击反馈重构
- **涉及文件**：`src/presentation/v2-actor-renderer.js`、`src/scenes/BattleScene.js`、`src/ui/solo-hud.js`
- **必须实现**：
  1. **真实机身轮廓阴影**：为主角、所有敌机、Boss 创建对应的同贴图轮廓阴影精灵（`depth: 4`，`tint: 0x02060e`，`alpha: 0.36`），跟随主机/敌机缩放与侧倾角度同步变化。
  2. **枪口火光与命中火花**：每次开火在炮口闪现像素光斑；子弹命中敌机时除了敌机闪白 `70ms`，在命中点朝反向飞溅 3–5 颗小火花。
  3. **击破爆裂、烟雾、顿帧与震屏**：普通怪爆裂出 12–16 颗像素碎片 + 2 团烟雾；精英/中型/Boss 击破触发 `28ms` 微顿帧 + 相机震动（`this.cameras.main.shake(...)`）。
  4. **连击（Combo）与暴击/机制飘字**：右上角或HUD显示当前连击数（如 `COMBO ×24`）；触发碎冰暴击、闪电链、护盾反震、黑洞坍缩时弹出克制清晰的短飘字（如 `碎冰 ×2.0!`、`反震清弹!`），同屏飘字上限 `8` 条防卡顿。
  5. **擦弹（Graze）正反馈**：敌弹擦过判定核外圈（`28px` 内未命中）触发青色电弧火花，自动补充 `+3%` 大招能量与 `+1` 零件，鼓励贴脸秀操作。
