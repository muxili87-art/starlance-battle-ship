# Codex 任务书 03：三关战役节奏、15 种敌机行为、3 名部位破坏 Boss 与音效

> **前置依赖**：完成 [codex-task-02-builds-balance.md](./codex-task-02-builds-balance.md)。
> **核心目标**：把零散刷怪升级为“3 分钟一关、高潮迭起”的街机战役体验，让 15 种敌机各司其职、3 名 Boss 具备可破坏部位与压迫感，并补齐复古科幻打击音效。

## 任务清单

1. **三关关卡导演（每关 3–4 分钟，节奏清晰）**
   - **第 1 关「高空突围」**：波次 1–4 小型编队 → 运输机补给波（快速跃迁冲刺）→ 精英混编 → 关底 Boss **拦截统帅（`boss_marshal`）**。
   - **第 2 关「钢铁防线」**：引入 `elite_shield`（双弧护盾机）、`elite_jammer`（电磁干扰）与炮艇/堡垒中型舰 → 关底 Boss **重装要塞（`boss_citadel`）**。
   - **第 3 关「主脑核心」**：高密度跨波混合编队 + 发射平台齐射 → 关底 Boss **核心主脑（`boss_overmind`）**。
   - **波次间快速跃迁冲刺**：每清完 2 波触发 1.5s 高速推进演出（背景加速 + 主角短暂前冲），让玩家有明确的“向前突进关卡”的感觉。

2. **15 种敌机差异化 AI 与弹幕可读性**
   - 为 `public/assets/manifest.json` 中的 15 种敌机全部接入对应行为：
     - `normal_*` 6 种负责数量压制、S 型穿插、斜向切入与自爆警报冲锋（自爆前闪烁红圈预警）。
     - `elite_shield` 带正面弧形减伤盾，鼓励穿透/电弧/走位绕击；`elite_missile` 发射可被击落的追踪导弹；`elite_jammer` 周期性扩散干扰波提示。
     - `medium_transport` 击毁必爆大量经验晶体与回血道具，是局内关键“抢资源节点”。
   - **弹幕规范**：所有敌方子弹必须高饱和亮色带白芯（品红/亮橙），飞行速度合理、留出明确穿弹缝隙。

3. **3 名多部位 Boss 战设计**
   - **部件破坏机制**：为 `boss_marshal` / `boss_citadel` / `boss_overmind` 挂载可独立受击破坏的左右武装挂载点（左翼炮/右翼炮/中央核心）。打掉任一侧副炮直接削减对应方向的弹幕/导弹齐射，鼓励玩家有策略地走位集火。
   - **两阶段转换**：50% 血量时触发短暂 `1.8s` 无敌护盾展开 + 震屏预警条，进入二阶段狂暴弹幕。

4. **Web Audio 复古科幻音效引擎 `src/audio/sfx-synth.js`**
   - 无需外部音频文件，用纯 Web Audio API 合成干净克制的街机音效（带全局静音开关与并发限流防爆音）：
     - 脉冲/激光/重炮/闪电开火音效（随攻速节流）
     - 击中金属反馈 & 敌机爆裂闷响
     - 吃经验晶体升调叮咚音（连吃音调逐渐升高）
     - 升级三选一弹出音、超武进化音、Boss 警报音与大招释放音

## 验收标准
- 完整打通第 1 关（约 3 分钟）并击败 `拦截统帅`，部位破坏后对应侧弹幕明显减少。
- 声音开关在暂停页与主界面可用，连吃经验与开火音效清脆不刺耳、无破音。
- 30 分钟连续跑图无帧率下降或控制台报错。
