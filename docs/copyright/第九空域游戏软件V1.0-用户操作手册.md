# 《第九空域游戏软件 V1.0》用户操作手册

**软件全称**：第九空域游戏软件 V1.0  
**软件简称**：第九空域（SECTOR NINE）  
**版本号**：V1.0  
**运行环境**：现代桌面及移动端 Web 浏览器（支持 HTML5 Canvas / WebGL 与 WebAudio API）

---

## 1. 软件概述

《第九空域游戏软件 V1.0》是一款以近未来深空空域防卫战为背景的 32-bit 像素风格竖版弹幕射击游戏软件。本软件采用模块化前端游戏引擎架构，内置 9 艘具备独立主武器体系、过载绝技与专属机师剧情的像素战机，提供「常规战役」与「无尽模式」两种游玩模式及「标准」「硬核」两档弹幕难度。软件支持桌面端鼠标/键盘与移动端触屏拖拽操作，并配备程序化多声部背景音乐与实时音效合成器、动态波次导演、战机强化构筑系统及本地战功勋章持久化系统。

---

## 2. 系统架构与核心模块说明

本软件由以下核心功能模块协同运行（与提交的源代码一一对应）：

1. **核心战斗引擎（`SoloCombat`）**：负责玩家战机与敌方单位的帧步进物理更新、子弹碰撞与擦弹判定、Boss 多部位独立受击与阶段切换、消弹转化黄金星晶机制以及防线漏怪警戒判定。
2. **动态波次导演（`StageDirector`）**：管理三大星域（高空突围、钢铁防线、主脑核心）的波次推进、中段精英旗舰、限时黄金运输舰悬赏、清屏加速机制，以及无尽模式下的双编队怪潮扩展与王牌敌机词缀分配。
3. **战机武器与强化系统（`SoloWeapons` / `upgrade-cards`）**：驱动 9 种差异化主武器、5 种副武器、5 种通用战术模组、3 种高危超频契约卡，并在满足主炮 3 级与对应副武条件时自动激活超武共振觉醒。
4. **会话状态与成就殿堂（`SoloSession` / `achievements` / `records`）**：管理生命值、护盾上限、等级经验、连击阶梯、擦弹狂热（FEVER）、无尽星域词缀（Mutator）及 12 项战功勋章与历史最佳战绩的本地持久化。
5. **交互界面与音频合成（`MenuScene` / `BattleScene` / `SoloHud` / `BgmSynth`）**：提供 32-bit 金属机台风格机库选机、分段式生命/护盾/经验读数、圆形过载充能按钮、机师剧情通讯条、战术强化三选一弹窗、暂停与结算弹窗及随场景自动切曲的程序化合成音频。

## 3. 机库整备与模式选择

启动《第九空域游戏软件 V1.0》后进入战机整备机库界面：

- **模式切换**：顶部左侧分段开关可切换「常规战役」（挑战三大星域三大 Boss 通关）或「无尽模式」（三大星域无限轮回并逐轮解锁全局词缀与高密度怪潮）。
- **难度切换**：顶部右侧分段开关可切换「标准」或「硬核」（提升敌弹速度、密度、伤害与精英配置，同时提高擦弹充能与分数倍率）。
- **战机与机师选择**：下方 3×3 战机阵列提供 9 艘可选战机（赤锋、疾风、雷霆、复苏、烈阳、虚空、寒星、天盾、蜂群）。点击任意战机即可在中央全息检视台预览机模，并在机师档案卡中查看其呼号、机师简介、火力/射速/耐久指标及历史最高评级。
- **战功勋章殿堂**：点击右上角「勋章」按钮可打开战功勋章殿堂，查看全部 12 项成就的解锁进度及各模式历史最高记录。
- **开始出击**：确认战机与模式后，点击底部金色「全军出击 · ENGAGE」按钮进入战场。

## 4. 战斗操作与实时战术界面

### 4.1 操作方式
- **鼠标 / 触屏**：在战场区域按住并拖动即可平滑牵引战机移动；战机自动持续开火。
- **键盘**：支持 `W/A/S/D` 或方向键移动；升级弹窗出现时支持按数字键 `1` / `2` / `3` 快速选择强化模块；战斗中按 `ESC` 暂停或恢复战斗。

### 4.2 战斗 HUD 说明
- **左上角状态区**：显示 `HP` 12 格分段生命条与数值、蓝色护盾条、金橙色经验条及当前等级 `LV.X`。
- **顶部中央星域徽章**：显示当前星域与波次（常规模式 `S1·W1`，无尽模式 `L1·S1·W1`）及本局计时。
- **右上角功能区**：显示实时得分、音效开关、暂停按钮（`Ⅱ`）、`COMBO` 连击计数。
- **状态指示条**：漏怪时亮起 5 格红色「防线警戒」指示灯；无尽模式第 2 轮起显示当前「星域词缀」；短时连续擦弹 5 次触发 `FEVER ×1.25` 狂热提示。
- **左下角 `OVERDRIVE` 能量环**：通过击杀敌机、前线输出与擦弹充能至 `100%` 后点击即可释放全屏绝技，瞬间将敌方弹幕转化为自动追踪的黄金星晶雨。
- **底部通讯条**：在出击、决战及释放过载时自动弹出当前机师的像素头像与战术语音字幕。

## 5. 战术强化模块与超武共振

当战机经验条蓄满升级时，战斗自动暂停并弹出「战术强化模块」三选一面板：

1. **专属主炮强化（金色）**：提升当前战机主武器的弹道数量、穿透或特效范围。
2. **副武器挂载（青色）**：从追踪导弹、环绕光刃、连锁电弧、爆破副炮、辅助机枪中选择装配；当主炮达到 3 级且装配了与当前战机匹配的共振副武时，触发**超武共振觉醒**（卡片呈品红脉冲高亮），立即清屏消弹并永久进化武器形态。
3. **通用模组与高危超频契约（钢蓝/契约）**：提供擦弹反击飞弹、棱镜分裂、狂热连杀、应急电容、磁力超频等战术被动；每逢 3 的倍数等级概率出现高风险高回报的超频契约卡。

## 6. 星域 Boss 战与无尽轮回

- **三阶段部位破坏 Boss**：每个星域末尾由「拦截统帅」「重装要塞」「核心主脑」镇守。Boss 拥有左翼炮/左肩/左孵化舱、右翼炮/右肩/右孵化舱与中央核心三个独立可破坏部位；优先击破左右部位可永久关闭其对应侧特色弹幕并触发消弹金雨。
- **无尽模式轮回机制**：在无尽模式下击败核心主脑后不会结束对局，而是回血并跃迁至下一轮回星域（`Loop 2+`），开启双编队怪潮、王牌词缀敌机与轮换星域词缀，直至战机耐久耗尽进入战果结算。

## 7. 暂停、结算与战功勋章殿堂

- **战斗暂停**：点击右上角暂停按钮或按 `ESC`，弹出「战斗暂停」面板，可查看当前出击战机与实时得分，支持「继续战斗」「音效系统开关」与「返回机库整备」。
- **战果结算**：通关或坠毁后弹出战果结算面板，展示综合评分、S/A/B/C 战果印章及击破数、最高连击、擦弹数与零件数统计，支持「再次出击」或返回机库。
- **战功勋章殿堂**：累计记录并持久保存 12 项战功勋章（包括超武觉醒、金雨洗礼、战神降临、不灭连斩、完美处决、深空破局者、星域收割者、永夜传说等）。
